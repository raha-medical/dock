# محاكي وكيل العتاد (للتطوير فقط)

ينفذ عقد القسم 16 (الطابعة والدرج) كما سينفذه الوكيل الحقيقي، بدون طابعة:

- كل إيصال أو تذكرة «تُطبع» تُحفظ ملف HTML في `out/`.
- فتح الدرج يظهر في النافذة كسطر `>>> فُتح الدرج` ويُسجل حدثاً.
- يتحقق فعلياً من توقيع توكن الدرج (ES256) ومن توقيع كتلة الإيصالات بالمفتاح العام من الخادم، ويرفض التوكن المكرر أو لإيصال آخر.

## التشغيل

`start-native.bat` يشغله تلقائياً. يدوياً:

```
node tools\agent-simulator\agent-sim.mjs
```

الواجهة تستخدمه عندما يكون في `alrahma-frontend/.env.local`:

```
NEXT_PUBLIC_AGENT_MODE=agent
NEXT_PUBLIC_AGENT_URL=http://localhost:9443
```

## تجارب مفيدة

- عطل طابعة: `set PRINTER=offline` (أو `paper_out`) قبل التشغيل.
- فتح الدرج يدوياً بالمفتاح المعدني (يجب أن يصل تنبيه للمحاسب):
  `curl -X POST http://localhost:9443/simulate/manual-open -H "Origin: http://localhost:3000"`
- اشتراط مفتاح الوكيل: `set AGENT_KEY=...` ثم أدخله في نافذة «الطابعة والدرج».
