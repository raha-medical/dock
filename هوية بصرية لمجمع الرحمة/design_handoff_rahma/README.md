# Handoff: نظام مجمع عيادات الرحمة الطبي (v5)

## نظرة عامة
نظام تشغيل متعدد الفروع لمجمع طبي. يضم واجهات الموظفين (الاستقبال، الطبيب، المختبر والأشعة، الصيدلية، المحاسب، الإدارة، دخول الموظفين)، وتطبيق المريض، وشاشة الانتظار العامة، والموقع التعريفي. التصميم مطابق لعقود الـ API النهائية (`api/api_contracts.md`، إصدار 2026-11-02).

## عن ملفات التصميم
ملفات `.dc.html` في هذه الحزمة **مراجع تصميم مبنية بـ HTML**: نماذج تُظهر الشكل والسلوك المطلوبين، وليست كود إنتاج يُنسخ كما هو. المطلوب **إعادة بنائها في بيئة الفرونت المعتمدة** (React / Next.js / Vue / Flutter…) بأنماطها ومكتباتها. إن لم تكن هناك بيئة بعد، فالمقترح: React + TypeScript + Vite (أو Next.js للموقع التعريفي)، مع Tailwind أو CSS Variables للتوكنز.

لفتح أي ملف: افتحه مباشرة في المتصفح (يحتاج `support.js` و`theme.js` و`lucide-icon.js` و`image-slot.js` بجانبه). ابدأ من `System Hub.dc.html` فهو فهرس لكل الواجهات.

- القالب (HTML) بين `<x-dc>` و`</x-dc>`، والمنطق في `<script type="text/x-dc">` كـ class فيه `renderVals()` يعيد البيانات والحالات.
- `{{ name }}` = قيمة من `renderVals()`. `<sc-for>` = تكرار، `<sc-if>` = شرط، `<dc-import name="X">` = مكوّن من ملف `X.dc.html`.
- البيانات في الملفات تجريبية (mock) وأسماء الحقول تتبع العقد قدر الإمكان.

## الدقة (Fidelity)
**High-fidelity.** الألوان والخطوط والمسافات والحالات نهائية. يُعاد بناؤها بدقة البكسل، مع دعم الوضعين الفاتح والداكن وواجهة RTL كاملة.

## مطابقة العقود
- `api/coverage.md` و`api/coverage.csv`: كل endpoint في العقد مع الشاشة والعنصر الذي يمثله (175 سطراً، منها 6 خلفية بلا واجهة: تجديد الجلسات، Webhook الدفع، لقطة الأوفلاين، تسجيل/حذف جهاز الإشعارات).
- عمود «جديد» يحدد ما أُضيف أو تغيّر في النسخة النهائية من العقد.
- سياسة الاستدعاء (`queue.call_next_by`: doctor | reception | both، و`queue.auto_call_next`) تتحكم بظهور أزرار الاستدعاء في الطبيب والاستقبال. جرّبها من Tweaks في `Doctor` و`Reception` (props: `callPolicy`, `autoCallNext`).

## التفاعل والسلوك
- **الوضع الداكن/الفاتح:** `theme.js` يضبط `data-theme` على `<html>` ويحفظه في `localStorage` بالمفتاح `rahma-theme`، ويتبع تفضيل النظام افتراضياً. زر `<theme-toggle>` في رأس كل واجهة.
- **الحالات الملونة** (الطابور، الدفع، الطلبات): كل حالة لها لون خلفية + لون نص + أيقونة، معرّفة في كائنات مثل `S = {called:[label,bg,fg,icon]}` داخل كل ملف.
- **حركة الشعار** (`Rahma Mark` مع `animate`): 2.6 ث، تبدأ عند ظهوره. رسم الهلال 0–1.2 ث، النبض 0.7 ث، الرأسان 1.05 ث، القلب 1.2 ث، اليدان 1.45 ث، الساق 1.7 ث، الأوراق 1.88 ث. Easing: `cubic-bezier(.22,1,.36,1)`، والنبض/الظهور `cubic-bezier(.34,1.56,.64,1)`.
- **الموقع التعريفي:** ظهور العناصر عند التمرير (translateY 28px→0 + opacity، 900ms، تأخير 110ms لكل مستوى)، بطاقات عائمة (±12px، 5–7 ث، لا نهائي)، شريط أقسام متحرك (42 ث خطي)، عدّاد الطابور يتغير كل 3.2 ث، خط رحلة المريض يُرسم عند الظهور. احترم `prefers-reduced-motion`.
- **الأخطاء والتحقق:** رسائل الأخطاء معروضة في الشاشات (OTP خاطئ مع المحاولات المتبقية، 409 نسخة جارية، وصفة مصروفة/منتهية، نتيجة مقفلة لعدم الدفع…). الاسترجاع والإلغاء والخصم وتعديل النتيجة المعتمدة تتطلب سبباً إلزامياً.

- الشعار: `assets/rahma-mark.svg` (فاتح)، والمكوّن `Rahma Mark.dc.html` بأربع نغمات: `auto` يتبع الثيم، `light`، `dark`، `white`.
